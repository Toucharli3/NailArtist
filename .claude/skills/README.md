# Skills partagés du projet NailArtist

Ces skills sont chargés automatiquement par Claude Code dans **chaque session** de ce dépôt
(ils s'activent tout seuls quand la tâche correspond à leur description).

Pour en désactiver un : supprimer son dossier. Pour en ajouter un : copier un dossier
contenant un `SKILL.md` valide ici.

## Skills installés

| Dossier | Rôle | Source |
|---|---|---|

| `frontend-design-engineer` | Art Director + Senior FE : construit des sites complets (8 directions visuelles, animations GSAP) | [angelapaia/frontend-design-engineer-skill](https://github.com/angelapaia/frontend-design-engineer-skill) |
