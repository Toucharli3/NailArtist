# 🖼️ Panneau d'administration — ajouter ses photos soi-même

Ce site est relié à **Pages CMS**, un panneau web gratuit qui permet à Margot de
**gérer ses photos et sa galerie depuis son téléphone**, sans toucher au code.

---

## Où se connecter

Rends-toi sur **ton-site/admin** (ex. `orangeblossomnails.fr/admin`) : c'est ta page
d'accueil admin, avec le bouton pour ouvrir ton espace. (Elle mène à app.pagescms.org.)

## Première connexion (une seule fois, ~2 min)

1. Va sur **https://app.pagescms.org** (ou clique le bouton depuis ta page `/admin`)
2. Clique sur **« Sign in with GitHub »** et connecte-toi avec le compte GitHub qui héberge le site.
3. GitHub demande d'**autoriser Pages CMS** à accéder au dépôt → accepte
   (tu peux limiter l'accès au **seul dépôt `NailArtist`**).
4. Dans la liste, choisis le dépôt **`NailArtist`**. Le panneau s'ouvre. ✨

> C'est tout : pas de mot de passe à créer, pas de serveur à installer.
> La connexion se fait uniquement avec GitHub.

---

## Ajouter une photo à la galerie

1. Dans le panneau, ouvre **« Galerie photos »**.
2. Clique sur **« Add an entry »** (ajouter).
3. **Photo** → *Upload* → choisis la photo depuis ton téléphone.
4. **Légende** → ex. « Chrome vert » (facultatif).
5. **Catégorie** → Pose gel / Nail art / French / Entretien (c'est le filtre du site).
6. Clique sur **« Save »**.

En 1 à 2 minutes, la photo apparaît en ligne sur le site. 🎉
Tu peux aussi **réordonner** (glisser-déposer) ou **supprimer** une entrée.

**Conseils photo** : format carré si possible, bonne lumière, poids < 500 Ko.

---

## Modifier les textes (nom, tarifs, bio…)

Les textes sont dans la page elle-même. Deux options :
- **Simple** : demande-moi, je les change.
- **Autonome** : sur GitHub, ouvre `index.html`, clique le crayon ✏️, modifie, puis
  « Commit changes ». Tout est expliqué dans **`GUIDE-PERSONNALISATION.md`**.

---

## En résumé
- **Photos** → panneau Pages CMS (app.pagescms.org), le plus simple.
- **Textes / couleurs** → `GUIDE-PERSONNALISATION.md`.
- Le site se **republie tout seul** à chaque changement.
