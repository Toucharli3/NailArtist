Orange Blossom Nails — gère tes photos et tes tarifs

Ouvrir mon espace →
  1. Clique sur « Se connecter avec GitHub » (ton compte).
  2. Autorise l'accès au dépôt NailArtist.
  3. Ouvre « Galerie photos » ou « Prestations & tarifs ».
  4. Ajoute / modifie, puis « Save ». Le site se met à jour tout seul 🌸

Pour une photo : Add an entry → choisis la photo dans l'entrée → Save.
